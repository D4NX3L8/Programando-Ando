# Simulacros de sustentación

Página estática de práctica para las Guías 1 y 2 de Programando Ando.

- Contiene tres exámenes para cada integrante (nueve en total).
- Cada examen tiene ocho preguntas de selección única, explicaciones y revisión de respuestas.
- El puntaje se calcula al finalizar; las respuestas no se envían ni guardan.
- No requiere instalar dependencias ni levantar un servidor.

Abre `index.html` en un navegador moderno. También puedes iniciar el servidor desde la
raíz del repositorio con `python3 -m http.server 8000` y visitar
`http://localhost:8000/examenes/`.
